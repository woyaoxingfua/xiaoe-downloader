# 小鹅通 M3U8 视频下载器（含 Termux / Android 平板移植版）

> **Fork 说明**：本项目 Fork 自 [likunqi/xiaoe-downloader](https://github.com/likunqi/xiaoe-downloader)，**完整保留原作者的全部代码、Git 提交历史与项目结构**，并在此基础上新增了 [Termux / Android 平板移植版](termux/)（`termux/` 目录）。原作者的所有贡献与智慧成果归属于 **[likunqi](https://github.com/likunqi)**，本仓库维护者仅完成了平台适配工作，并向原作者致以诚挚感谢。🙏

一款面向**个人学习场景**的本地工具：浏览器端通过 Tampermonkey 油猴脚本自动嗅探小鹅通（xiaoeknow）平台视频的 `.m3u8` 流地址，发送给本机 Python 下载器，完成多线程下载、AES-128 解密与 ffmpeg 合并，最终得到可用于**本地 AI 知识提取**的视频文件。

## ✨ 项目功能

### 工作流程

```
浏览器打开小鹅通课程页
        │
        ▼
油猴脚本拦截 XHR/Fetch 中的 .m3u8 地址（含 iframe 内嵌播放器）
        │
        ▼  点击「发送到下载」
本地 Python 下载器（127.0.0.1:8910）接收任务
        │
        ▼
请求 M3U8 索引 → 解析 TS 分片与 AES-128 密钥
（自动展开嵌套/混淆 M3U8，Token 过期预检）
        │
        ▼
6 线程并发下载分片 + AES-128-CBC 解密（失败自动重试 3 次）
        │
        ▼
ffmpeg 合并为 MP4 ──失败──▶ 自动回退重编码
        │
        ▼
ffprobe 时长校验（Termux 版），成品存入 downloads/
```

### 核心特性

| 能力 | 说明 |
|------|------|
| 🔍 自动嗅探 | XHR + Fetch 双重拦截；Termux 版油猴脚本 v1.2 支持 iframe 内嗅探 + performance 资源补扫，防漏抓 |
| 🔐 AES-128 解密 | 密钥 + IV 自动处理，IV 按 HLS 标准随分片序号递增 |
| 🪆 嵌套 M3U8 展开 | 自动探测小鹅通私有混淆索引（外层分片 ≤ 2 时逐层展开） |
| ⏱ Token 预检 | 解析 URL 中的过期时间参数，提前预警 403 |
| ⚡ 并行下载 | 6 线程并发 + 进度条，最多 3 个视频排队 |
| 🎬 智能合并 | 无损重封装优先，失败自动回退重编码；Termux 版增加 TS 二进制拼接 + genpts 时间戳重建 + ffprobe 时长校验 |
| 🧰 自动装依赖 | 启动时自动 pip 安装缺失依赖（清华镜像） |
| 📄 完整日志 | 控制台 + downloader.log 双输出，含错误诊断（403/404/401 分场景提示） |

## 🖥️ Windows 使用方法（原版）

### 1. 安装油猴脚本

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展
2. 打开 `小鹅通视频 m3u8 地址嗅探提取器.js`，复制全部内容
3. Tampermonkey → 添加新脚本 → 粘贴 → 保存

### 2. 启动下载器

- 方式 A（推荐）：双击 `启动.bat`（自动寻找 Python，也可使用捆绑的 WinPython）
- 方式 B：命令行执行 `python -u downloader.py`

> Windows 版使用仓库内捆绑的 `ffmpeg.exe`，需将其与脚本置于同一目录（或确保其在系统 PATH 中）。

### 3. 开始下载

打开课程视频页 → 浮窗弹出 → 点击「发送到下载」→ 成品保存在 `downloads/`。

## 📱 Termux / Android 平板使用方法（本 Fork 新增）

在 **Android 平板**上实现"浏览器 + 下载器"一体机：平板浏览器嗅探 → 本机 Termux 下载，无需电脑中转。

> ⚠️ **必须使用 venv 虚拟环境**（Termux 全局 Python 受 PEP 668 保护，直接 pip 安装会被拒绝）。ffmpeg 通过 `pkg install ffmpeg` 安装，不再使用捆绑的 exe。

完整安装步骤、稀疏克隆（可跳过 100MB 的 ffmpeg.exe）、常见问题，请参阅 **[termux/README.md](termux/README.md)**。

快速开始：

```bash
pkg update && pkg install python ffmpeg git
git clone --depth 1 --filter=blob:none --sparse https://github.com/woyaoxingfua/xiaoe-downloader.git
cd xiaoe-downloader && git sparse-checkout set termux && cd termux
python -m venv venv && source venv/bin/activate
python downloader.py   # 自动安装缺失依赖并重启
```

## ❓ 常见问题

**浮窗未弹出**：确认 Tampermonkey 已启用、当前域名在 `@match` 列表中；打开浏览器控制台查看 `[油猴嗅探器]` 日志。

**启动报错**：Windows 检查 ffmpeg.exe 是否在同级目录；Termux 执行 `pkg install ffmpeg`；检查 8910 端口占用。

**下载 403**：m3u8 链接有时效性。刷新课程页面重新嗅探，立即点击发送。日志会显示 Token 剩余有效期。

**合成的视频时长不对**：Termux 版已内置 ffprobe 校验与重编码回退；若仍异常，多半是分片下载不完整（看日志中的成功片数）。

**Termux 后台被杀**：通知栏常驻 Termux 会话、关闭电池优化、使用 `termux-wake-lock`。
